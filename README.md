# RuBaMM

Exploring porting and bridging [PyBaMM](https://pybamm.org/) battery models to Modelica compiled via [Rumoca](https://github.com/cognipilot/rumoca).

## Environment Setup

Activate the local virtual environment:

```powershell
.\.venv\Scripts\Activate.ps1
```

Run verification tests:

```powershell
.\.venv\Scripts\pytest
```
